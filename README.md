# Hermes Restaurant Cost Controller

A specialized Hermes profile for restaurant invoice processing, item-price tracking, purchasing-cost analysis, and sales comparisons.

## Included

- Installable profile distribution
- Specialist SOUL.md
- Restaurant cost-control skill
- Profile-creation prompt
- Excel workbook template
- Invoice normalization and validation helper
- Example invoice and sales files
- Configuration and setup documentation

## Tracks

Invoice totals, vendors, line items, new products, price history, price alerts, weekly or monthly sales, purchases as a percentage of sales, sales minus purchases, estimated purchase margin, and optional inventory-adjusted COGS.

It does not infer shelf inventory from invoices or calculate true net profit without complete expenses.

Start with `QUICK_INSTALL.md`.
